# AI capability and product-design research preview

Snapshot date: 2026-08-21

This is a frozen, auditable research preview, not a complete global census or a publication-validated dataset. It contains one row for every product-configuration–task assessment in the frozen catalog. Explicitly pending rows use `IE` across all stages until coding is complete; a coded `IE` instead records insufficient evidence for a specific stage. Both are excluded from numerical gap summaries.

The task-level `task_coverage` table is mandatory context: it reports the current lower-bound product count, design-coding coverage, unresolved leads, search status, saturation status, and next required work. Reaching a product-design score of 4 never ends product discovery.

Gap is defined as AI capability minus product design. Positive values indicate technical capability above the documented authority of the assessed product configuration; negative values can occur because product design measures intended workflow authority while capability requires separate performance evidence.

Read the four included protocol files before analyzing the data.
